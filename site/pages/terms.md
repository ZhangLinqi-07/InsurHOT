页首说明：

> InsurHOT 聚合保险监管、行业研究、险企披露与媒体报道，用模型生成中文摘要与精选，原文版权归各来源所有。本地试运行提供网页、RSS、公开 API 与 MCP 阅读入口。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请以原文为准。监管决定、征求意见稿、协会声明和研究观点保留各自文件状态及适用司法辖区。当前信源配置只展示摘要与原文链接，默认关闭全文展示和全文再分发。

## 2. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过反馈页联系我们，我们会尽快处理。

## 3. 使用本站的数据

请写明你允许的用途（例如个人阅读、组织内部使用），以及需要事先取得你同意的用途（例如商业产品、公开转载、批量再分发）。

## 4. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试。

本站按“现状”提供，不保证内容完整、准确和持续可用。
