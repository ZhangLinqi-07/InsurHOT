# 总览与新闻雷达

总览位于 `/overview`，新闻雷达位于 `/radar`。桌面侧栏将两个入口放在精选前方，手机从我的页面进入。首页仍为原有精选，原有底部导航、字体设置、主题、信源与信息分类保持原有实现。

总览沿用关于页的统计口径，显示启用信源、收录动态、精选报道和已出日报。联动观测台参考 HTML 中的连续动态结构，以同一条公开报道串起材料扫描、立体星图、新闻流和焦点观察。旋转轨迹、星图节点、当前报道卡片及新闻流共享选中项和回放进度，三臂星图分别对应真实信源、报道和公开分类，已有标签作为补充说明。背景星尘仅作装饰。页面继续使用站点现有的品牌、字体和主题。

直接打开总览时自动回放，每条报道持续八点四秒，可暂停或调整速度。带有 `item` 参数进入时保留指定报道并暂停，便于从阅读页返回。点击星图、新闻流或报道队列会同步选中该报道并暂停回放。减少动态效果设置下呈现静态画面，手动选择仍可使用，页面进入后台时停止推进动画。

总览可见时每三十秒通过既有 loader 重新读取公开报道，也保留手动刷新。与上次读取相比新出现的报道 ID 会进入待播放队列，回放中优先衔接新增报道，暂停时显示播放新增报道按钮，当前阅读内容继续保留。刷新后已经撤回或离开当前公开范围的报道会从展示中移除。这一变化表示公开报道进入本页数据范围，可能包含历史补录或重新公开，不能据此判定刚刚完成抓取。动画各阶段表达报道浏览过程，不代表实时模型处理状态。

新闻雷达按原文发布日期及现有分类绘制。可切换近三十天、近九十天和全部日期，通过圆点、相邻报道或滑块选择报道，也可筛选分类及搜索标题、摘要、来源与标签。选择会保存在网址中，进入报道再返回时保留选中项。手动启动回放后可调整速度，手动选择会暂停回放，后台页面不继续回放，并遵守站点的减少动态效果设置。

数据从 `/api/site/insurance/radar` 读取，经 `packages/backend/src/publication/radar.ts` 使用既有公开范围规则查询。日期窗口采用北京时间自然日，包含今天并以请求时刻截止。无发布日期、未来日期、未公开、尚未放行或不属于公开动态的内容不进入图表。最多返回最近六百条，接口同时返回窗口总量和截断标志。超过上限时页面明确说明图表与筛选覆盖的范围，并提供全部动态搜索入口。

初筛相关材料保留原文标题与来源摘录。接入[保险关键词分类](insurance-classification.md)后，业务类别读取公开投影中已计算的十一类结果，不从标题推断地域。尚未完成分类刷新的旧记录仍显示未分类。参考文件只用于借鉴动态呈现和联动结构，其中静态新闻、统计数字及其他页面没有导入。总览与雷达均不新增模型调用、采集任务、环境变量或数据库迁移，自动刷新只读取既有公开接口。
