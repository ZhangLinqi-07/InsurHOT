# 国内与国际保险报告

新新闻的自动筛选、规则分类、评分与定时出刊由 [新新闻自动工作流](insurance-workflow.md) 衔接。首次启用后只消费新增新闻，历史积压继续保留，日报周报月报仍使用本文的既有成刊口径。

每期日报、周报和月报分为国内动态与国际动态，版内沿用监管、行业、产品、再保险、科技、研究与解读栏目。国内包含中国内地及港澳台。报告分版保留基于原文事件市场证据的既有口径，独立于动态列表按信源地区划分的筛选。跨境事件只在国内版完整呈现。全球性和地域尚未明确的事件单列，不根据媒体地址、语言或机构总部猜测市场。

各版先按原有重要性排序，成刊选稿依次考虑每版排名靠前的事件，再考虑各版下一件事件。入选门槛、事件去重、跟进条件与单信源限制不变，整期正文仍最多十二件、周报二十件、月报三十件。某版材料不足时由其他版自然补足，不凑条数。

日报的分版导读摘用该版首件事件已有摘要中的完整句子。周报模型分别概括各版本周新增进展，月报分别概括有依据的月度变化，仍只使用日报正文中的事实。各版导读与栏目导读分别校验自己的材料范围，涉及引用撤回时不再展示该版原导读。没有可用模型文字时使用该版首件事件的原有文字，页面阅读不调用模型。

固定日报时段仍为前日北京时间八点至当日八点。周报覆盖对应自然周的日报，月报覆盖对应自然月的日报。只有实际出刊的报告才进入网站归档、公开接口、RSS 与 Agent 出口。

## 首期编排

初始化导入的材料带有归档标记，常规日报不会使用。需要为尚未出过日报的站点编排首期时，可以显式运行下面的命令。它只读取当期原文发布时间范围内、目前仍公开且已经入选的材料，不修改归档标记、评分或精选状态，不调用模型，不把历史资料当作今天新消息。页面与公开出口保留首期编排说明。

```powershell
.data/runtime/node.exe scripts/insurance/local-node.mjs scripts/insurance/publish-daily.ts 2026-10-30 --initial
```

这个命令拒绝覆盖已有日报。后续定时出刊继续采用到达及公开时间口径，首期编排不是定时任务的兜底。
