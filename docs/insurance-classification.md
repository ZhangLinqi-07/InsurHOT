# 保险新闻关键词分类

本站采用新闻关键词分类离线复现包 v2 的固定规则计算最终栏目。大模型继续提取内容标签、主体机构、资料范围、事件事实、原文证据和适用条件。最终分类在中文标题和摘要生成后计算，公开投影也会在写入时按最终展示文字重新计算，因此初筛通过、尚未完整分析的资料同样可以获得栏目。读者访问页面只读取已经保存的结果。

## 分类口径

新版栏目为监管、企业、市场、研究、产品、理赔、再保险、投资、科技、风险和其他。已有同义栏目继续使用原来的技术标识，其中企业为 `industry`，研究为 `paper`，产品为 `products`，科技为 `insurtech`。其余沿用复现包的技术标识。原有 `opinion` 标识仍供历史记录、已保存的查询及订阅读取，新规则不再给新闻分配该类别。解读和实践仍可以作为模型抽取的内容标签保留。

分类定义及展示属性位于 `industry/taxonomy.ts`。固定词库位于 `industry/classification/keywords-v2.json`，包含 5,164 条中英配对词条。`modules/insurance/backend/classification.ts` 实现本地匹配，保留原版的 Unicode 规范化、大小写折叠、英文边界、长词优先、概念去重和决胜顺序。

主要词基础分为 10，次要词为 3，标题及原文标题的命中权重为 2，摘要为 1。同一类别内以英文对应词确定词条概念，多次命中只保留最高分。总分相同后依次比较主要词得分、标题得分、命中词条中文名称的最长长度和词库类别顺序。无命中时归入其他。机构全名和简称仍依照原包作为独立词条维护。

本次接入保持 v2 原规则，包括其英文机构缩写与普通单词可能歧义的现有行为。规则调整应另行形成版本并评估分类变化。输入正文、来源名和新闻价值分均不参与关键词分类。分类分值与新闻价值分独立保存，不参与精选门槛。

分类完成后可以单独执行[新闻阅读价值评分](insurance-reading-score.md)。该任务只读取已有分类的标题与摘要，不重新运行分类或结构抽取。

## 记录与人工更正

完整分析在 `analyses.output.classification` 保存规则版本、原包类别、各类得分、命中字段、位置和分值。公开投影在 `publications.classification` 保存按最终展示文字计算的同类证据，初筛资料也有该记录。词库版本包含固定文件的 SHA-256 摘要。后台内容诊断页可以展开关键词分类依据，公开接口继续返回原有的新闻价值分字段。

人工明确指定的栏目优先于规则建议。更改标题或摘要后，规则在公开投影重建时重新计算。人工指定的标签、主体及事件归属继续按原有流程处理。

## 历史内容更新

部署前运行数据库迁移，新增可空的 `publications.classification` 字段。先执行 `node --env-file=.env scripts/insurance/reclassify.ts` 查看当前投影的分类变化，再附加 `--run` 执行。Windows 本地环境可通过 `node scripts/insurance/local-node.mjs scripts/insurance/reclassify.ts` 加载本站配置，执行时同样附加 `--run`。

每次运行在 `.data/classification/` 下保存执行前的类别、原有分类依据和汇总结果。刷新操作只更新栏目、分类依据及投影版本，保留标题摘要、新闻价值分、精选状态、事件归属及发布时间，不调用模型。执行时重新读取当前投影并遵守人工栏目更正，不把旧快照文字写回正在更新的新闻。

引用该新闻的标准日报、周报和月报同步移动到新栏目，保留原条目、头条和入选决定，并通过原有报告修订表保留旧内容。旧版标准栏目名称会被识别，人工撰写的非标准主题标题继续保留。历史分析及付费回执保持原始记录。此更新不删除新闻或分析数据。

## 验证

接入时对复现包全部 3,180 条新闻逐条比较类别、各类得分、完整命中记录及主次词得分，与 Python 原版一致。仓库测试另外覆盖保留结构模型调用和原文证据、人工栏目优先、初筛资料分类、历史刷新幂等以及新闻价值分与精选状态保留。
